# My AI Prompt Library

Prompts I actually use every day running my Chinese cooking video course business (cross-border e-commerce, digital products).

## 1. Recipe Translation (CN → EN)

```
Translate this Chinese recipe into natural English for American home cooks.
- Convert all units to both metric and US cups/spoons.
- Replace hard-to-find ingredients with common US supermarket alternatives, note the substitution.
- Keep the steps in order, numbered.

Recipe:
[ paste here ]
```

## 2. Gumroad Product Description

```
Write a Gumroad product description for my Chinese cooking video course.
Course: [name]. Includes: [number] lessons, [extras].
- Hook in the first 2 lines. Benefits, not features.
- Friendly, confident tone. End with a clear call to action.
```

## 3. Short Video Script (TikTok / YouTube Shorts)

```
Write a 30-second vertical short script to promote my Chinese cooking course.
Dish: [name]. Goal: stop the scroll in the first 2 seconds.
Format: HOOK (0-2s) / COOKING MONEY SHOT (2-20s) / CTA (20-30s).
Include on-screen text suggestions.
```

## 4. Thumbnail / Title Ideas

```
Give me 10 YouTube thumbnail title ideas for a video teaching [dish].
Rules: under 6 words, curiosity-driven, no clickbait lies.
```

## 5. Customer Reply Template

```
Draft a friendly reply to a customer who says: "[message]".
Keep it short, helpful, and warm. Offer one concrete next step.
```

## Notes

- I keep prompts in English because my target market is US / Taiwan / Europe.
- Every prompt gets iterated: run → check output → tighten the rules → save the winner.
